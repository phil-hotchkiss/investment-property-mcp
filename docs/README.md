# Docs index

- `docs/prd.md`: the product requirements, milestones, and domain rules.
- `docs/decisions/`: ADRs, the template, and `backlog.md` with raw material for ADRs not yet written.
- `docs/fixtures/`: worked arithmetic behind every number asserted in core tests.
- `docs/guides/`: how-tos, such as MCP client setup and secrets.
- `docs/history/`: milestone records kept for reference, such as the M0 inventory.
- `prompts/`: runtime prompts loaded by code, such as the shared agent system prompt.
- `evals/`: how to run and read evals, and the observed failures log that cases cite as evidence.
- `packages/evals/cases/`: one YAML file per eval case, with its own README on the format.
